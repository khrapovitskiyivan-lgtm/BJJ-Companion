# Новые карточки из канала «Моё БЖЖ»: источники

Черновики написаны по открытым источникам (уверенность medium), сверены редактором. Механику стоит подтвердить по видео тренера.

## 695 Ассасин чоук (Assassin Choke)
- уверенность: medium
- неясно: Пошаговой механики в открытых источниках нет (инструктаж платный); шаги реконструированы по описанию: распятие плюс лацкан вокруг шеи. Чей лацкан используется, не уточнено. Тренер ставит в один ряд с ниндзя/Канто: связь источниками не подтверждена.
- источники:
  - https://www.bjjee.com/?p=78518
  - https://www.bjjee.com/?p=92525

## 696 Шаолинь свип (Shaolin Sweep)
- уверенность: medium
- неясно: Точные захваты зависят от версии (Шаолинь, Галван, вариант из обратного кеса-гатаме). Связь с кимурой/свипом из подписи тренера не проверена.
- источники:
  - https://ibjjf.com/news/vitor-shaolin-teaches-the-world-famous-shaolin-sweep
  - https://bjjcanvas.com/?p=7462
  - https://www.grapplearts.com/?p=1913
  - https://live.atosbjjondemand.com/videos/shaolin-number-1-sweep-part-4

## 697 Хеликоптер армбар (Helicopter Armbar)
- уверенность: medium
- неясно: Есть вариант-свип и вариант-болевой; по подписи тренера взят болевой. Пошаговой механики в бесплатных источниках мало, шаги по общему описанию (томоэ-наге + армбар).
- источники:
  - https://www.bjjee.com/articles/make-them-rethink-their-lives-with-this-helicopter-armbar-setup/
  - https://evolve-university.com/library/intermediate/?tag=zoro
  - https://graciebarra.com/gb-news/gb-learning-straight-armlock-variations

## 698 Чоибар (Choi Bar)
- уверенность: medium
- неясно: Детальная механика финиша только в платных курсах; шаги по общему описанию. Свип-вариант из подписи тренера отдельно не расписан.
- источники:
  - https://www.bjjee.com/articles/craig-jones-choi-bar-2nd-fastest-submission-at-the-adcc/
  - https://live.atosbjjondemand.com/the-choi-bar-series
  - https://ms.player.fm/series/beyond-jiu-jitsu/ep-145-a-deep-dive-into-the-choi-bar

## 699 Гибрид гард (Hybrid Guard)
- уверенность: medium
- неясно: Hybrid guard не имеет единого канонического определения: обычно так зовут комбинацию спайдер+лассо или спайдер+ДЛР с захватом двух рукавов. Точная конфигурация у тренера не проверена по видео.
- источники:
  - https://www.bjjee.com/?p=24004
  - https://jitsuiq.com/grips/material-grips/spider-guard-sleeve-grip.html
  - https://evolve-mma.com/blog/complete-guide-to-the-bjj-lasso-guard/

## 700 Тарикоплата (Tarikoplata)
- уверенность: medium
- неясно: Легальность IBJJF: в таблице брифа нет явной строки; считаю как кимура-семейство (плечевые болевые легальны всем взрослым), официального подтверждения не нашёл. Различие с баратоплатой в источниках описано по-разному.
- источники:
  - https://www.bjjee.com/articles/tarikoplata-the-most-savage-shoulder-lock-tarik-hopstock/
  - https://evolve-mma.com/blog/bjj-shoulder-locks-understanding-the-differences-between-tarikoplata-and-baratoplata/
  - https://app.digitsu.com/t/tarikoplata
