# Независимый конкурентный анализ v2 — BJJ Companion

Дата: 2026-07-29. Роль: аналитик рынка (`.claude/agents/bjj-market-analyst.md`), анализ
выполнен контролёром в роли. Свежая веб-разведка (июль 2026), НЕ пересказ отчёта
2026-07-22 — выводы построены заново, расхождения с v1 отмечены явно.
Маркировка: (факт) — подтверждено источником; (оценка) — суждение аналитика.

## TL;DR

1. **Рынок за неделю не подешевел, а поумнел.** Волна AI voice-first дневников — уже
   минимум ТРИ живых приложения (GrapplingAI, BetterBJJ, Jits AI). Ручной ввод дневника
   коммодитизируется голосом+AI. Это главная растущая угроза ядру.
2. **RU-окно всё ещё открыто.** Прямой RU-конкурент Universal App — по-прежнему ранний
   доступ/предзапись, живого продукта не видно (факт: сайт в предзаписи, отзывы
   витринные; сайт не отдаёт TLS-соединение стороннему фетчеру). Специализированного
   живого RU-дневника БЖЖ в поиске нет (факт). Окно не вечное.
3. **Кабинет тренера коммерчески валидирован конкурентом.** BJJ Notes запустил
   B2B «for Gyms» за $49/мес: ростер, посещаемость, промоушены поясов и главное —
   «engagement signals» (active/drifting/quiet) до того, как ученик тихо уйдёт (факт).
   Категория «зал платит за удержание» больше не гипотеза — лидер сегмента уже продаёт
   ровно это. Для RU это одновременно подтверждение направления и фора: их продукт в РФ
   не приживётся (язык, оплата, не-Telegram).
4. **Геймификация сама по себе не продаёт.** Jits AI (XP, миссии, стрики, лидерборды,
   Nemesis Engine) просит $99-129/год и ловит отзывы «XP вместо обучения», «дорого для
   сырого приложения» (факт). Наш бесплатный XP-слой — норм как удержание, но это не ров
   и не ценность для монетизации.
5. **Вердикт не изменился по сути: бизнес — НИЗКО, нишевый RU-продукт — СРЕДНЕ,**
   но продукт с 2026-07-22 заметно дозрел (340 техник, обратный поиск, «Что если»,
   партнёры, XP, PDF-инструкция), а RU-окно подтверждено открытым. Сдвиг внутри
   «СРЕДНЕ» — вверх (оценка, уверенность средняя).

## 2. Что изменилось в НАШЕМ продукте с v1 (для честного сравнения)

340 техник (было 310), словарь 78 терминов с тап-поповерами, поисковые алиасы на 145
карточек (сленг/EN/дзюдо), обратный поиск «найди приём по описанию» (5 веток),
матрица «Что если» без пустых слотов, XP/уровни, партнёры по залу с недельным статусом,
крючок «Разбери показанное», soft-пинги бота, PDF-инструкция в боте, гейт согласия.
Это уже не «журнал + база», а связная петля с уникальными кусками.

**Чего нет ни у одного конкурента из карты** (факт по итогам прогона):
- Обратный поиск «опиши, что с тобой сделали -> карточка + защита».
- «Чем поймали» -> защиты, выведенные из графа связей.
- Telegram-native: zero-install, бот-напоминания по НЕДЕЛЬНОМУ ПЛАНУ (не тупой daily),
  партнёрство по подотчётности плана.

**Где мы объективно позади:**
- Ввод: у нас руки, у волны AI — голос. Трение логирования у них ниже.
- Платформа: нет App Store/Play присутствия = нет их каналов дискавери.
- EN-аудитория: интерфейс RU-only (осознанно отложено).
- Команда: соло против нескольких funded/полных команд.

## 3. Рынок и воронка (без изменений против v1, повторная проверка не дала новых цифр)

хобби-выручка (оценка). Якорь цены уточнён: BJJ Notes PRO $59.90/год — главный мировой
якорь; Jits AI $99+/год уже получает отпор. 390 руб/мес (~4700 руб/год ~ $50) — у верхней
кромки якоря; годовой тариф со скидкой почти обязателен (оценка).

## 4. Ров — переоценка

- Копируемость фич по-прежнему высокая. Отдельно: голосовой AI-ввод конкуренты уже
  сделали нормой — «инсайты из дневника» дифференциатором быть перестают (факт тренда).
- Самое устойчивое у нас: (а) Telegram-native RU-дистрибуция; (б) курированный
  RU-контент 340+78+145 алиасов — это месяцы ручного труда, который LLM-конвейером
  конкурент быстро не повторит С КАЧЕСТВОМ (в нашей же ревизии выловлены галлюцинации
  типа «Обратный серп»); (в) обратный поиск + «Что если» как продуктовые находки —
  копируемы, но пока ни у кого.
- НОВОЕ соображение: Telegram голосовые — культурная норма RU. Голосовой ввод дневника
  через voice message бота технически доступен и нейтрализует главное преимущество
  AI-волны на нашем поле (оценка; направление, не обязательство).

## 6. Стратегические выводы (перерешено заново, не скопировано)

1. **Скорость важнее полировки: RU-окно открыто, но конечно.** Universal App в
   предзаписи, AI-волна пока EN-only. Каждый месяц без живых RU-пользователей — аренда
   окна впустую. Мягкий запуск на зал/круг — правильный ближайший ход.
2. **Кабинет тренера повышен в приоритете.** BJJ Notes Gyms доказал: категория платит
   $49/мес. Консьерж-тест на своём зале (план п.30.H) — теперь не «эксперимент», а
   проверка ВАЛИДИРОВАННОЙ категории на RU-почве. Прежний порядок (сначала консьерж,
   потом код) остаётся верным.
3. **Ответ AI-волне готовить, но не паниковать.** Наш SAM (RU, Telegram) их волной пока
   не накрыт. Среднесрочно — голосовой ввод через бота как asymmetric-ответ. Не строить
   сейчас; заложить в бэклог после запуска и телеметрии.
4. **Видео — подтверждено НЕ строить** (третий независимый прогон, тот же вывод).
   Курированные бесплатные ссылки по спросу из телеметрии — достаточно.
5. **Цена: годовой тариф обязателен.** Мировой якорь $59.90/год; 390 руб/мес без
   годового будет читаться дорогим. Монетизацию по-прежнему не включать до роста.
