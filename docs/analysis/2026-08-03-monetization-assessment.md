# Монетизация BJJ Companion — оценка и выбранная модель

Дата: 2026-08-03. Под цель «сделать проект продаваемым» (exit). Оценка двух независимых экспертов (продуктовый + рыночный аналитик), консенсус + решение владельца.

## Выбранная модель (РЕШЕНИЕ)

**Приложение бесплатное. PRO = видео + возобновляемая персональная программа за 1499 руб/год.**

- FREE (ядро, не за стеной — сохраняет петлю удержания и рост): дневник, статистика/«стиль», граф 340 техник, текст-рекомендации, «Что если», обратный поиск, словарь, геймификация, партнёры, напоминания, стартовый набор. Плюс бесплатное демо-видео на стартовом наборе (20-40 техник) — доказывает качество съёмки и активирует новичка.
- PRO (1499 руб/год, годовой recurring): полная видео-библиотека + персональная программа «месяц закрытия твоей дыры» с видео под каждый дрилл (пересобирается из свежего дневника) + разбор показанного на тренировке. ВАЖНО: продаём НЕ «склад роликов», а «видео + возобновляемую программу» — иначе отток после первого года (истощение статичного контента).
- Опции (по желанию): месячный тариф ~149-199 руб/мес рядом с годовым (снизить барьер первого платежа); дешёвый founder-lifetime рано для быстрого пруфа спроса.
- Пейволл только в точке intent (видео закрытой техники через крючок «разбери показанное»; экран «программа закрытия дыры»). НИКОГДА не на привычке (дневник/рекомендации/партнёры бесплатны).
- Платёжка: Telegram Stars (нетто разработчику ~55-70% после комиссий Apple/Google + вывод TON; 1499 -> нетто ~825-1050 руб). Легитимный мост для RU-пруфа (обходит заблокированные карты).

## Главный вывод оценки (оба эксперта, независимо)

Монетизация здесь = ПРУФ спроса (willingness-to-pay) + ценность актива, НЕ доход. Рынок мал структурно: RU/CIS BJJ SAM ~3-15 тыс (оценка), потребительская подписка КОНСТРУКТИВНО не выходит даже на ~$3-4k MRR. И сама выручка почти не двигает цену продажи. Цену несут: ВИДЕО-АКТИВ + чистая кривая УДЕРЖАНИЯ на реальной когорте + решённая ЮРЧАСТЬ. Гнать пейволл на малой базе рискованно — может подрезать рост/retention, которые покупатель ценит выше выручки. Поэтому монетизация лёгкая (доказать WTP), приложение в основном бесплатное.

## Ключевые предупреждения (учтено в модели)

- НЕ снимать все 340 на спекуляцию: сначала топ 30-60 (фундаментал/стартовый набор по спросу+центральности, = партия 1 плана съёмки docs/analysis/2026-08-02-video-shooting-order.md), пейволл на них, доказать конверсию, ПОТОМ достраивать библиотеку (заодно = повод продлевать подписку).
- 390 руб/мес ОТКЛОНЕНО (у верхней кромки мирового якоря, опрос: «дорого»). Мировой якорь у нуля: BJJ Notes free/$59.90год, MatTime $9.99 lifetime, Ujitsu $34.99/год.
- Истощение контента = главный риск модели -> лечится растущей библиотекой (дозы) + обёрткой-программой + крючком после класса.
- 242-ФЗ и RU-платёжное юрлицо не решены -> потолок раскрутки И дисконт при продаже. Решить перед активной раскруткой/продажей.

## Порядок внедрения (когда реализуем; не раньше чем видео снято и метрики стоят)

- Фаза 0 (S): метрики retention D1/D7/D30 + воронки (SQL-разрезы по bjj_events) + бесплатное видео на стартовом наборе.
- Фаза 1 (M): Stars-пейволл на полную видео-библиотеку (isPremium в типах есть, но не задействован; entitlement на сервере — createInvoiceLink + вебхук successful_payment + запись права; пейволл-экран в точке intent). Видео заезжает по мере съёмки.
- Фаза 2 (M-L): возобновляемая программа «месяц закрытия дыры» с видео под дрилл (кирпичи есть: workoutCluster, caught.ts, gap-логика).
- Фаза 3 / параллельно руками: B2B кабинет тренера (категория валидирована BJJ Notes Gyms $49/мес; RU-ниша пуста; высший потолок выручки и лучший сюжет для покупателя-консолидатора; гейт на 242-ФЗ + консьерж-валидация на своём зале). См. docs/superpowers/plans/2026-07-28-trainer-cabinet.md.

## Реалистичные исходы продажи (оценка аналитика, низкая уверенность)

- Как есть (pre-revenue): ~$2-15k (код + часть контента + крошечная аудитория).
- С доказанной когортой (50-200 платящих, хороший retention) + готовой видео-библиотекой: ~$15-80k (видео тянет большую часть).
- Видео-библиотека — самый ценный независимо продаваемый кусок (лицензируется/перепродаётся отдельно от кода).
- Вероятные покупатели: RU сеть залов / грэпплинг-медиа / федерация, консолидатор gym-софта, более крупная BJJ-платформа (Ujitsu), Telegram-экосистемный игрок.

## Вердикт по шансам (аналитик)

- Монетизация как заметный бизнес: НИЗКО (уверенность высокая).
- Как малый доход + enabler продажи: НИЗКО-СРЕДНЕ (средняя).
- Продаваемость проекта: СРЕДНЕ при условии проф-видео + доказанного retention + решённой юрчасти; иначе НИЗКО.
