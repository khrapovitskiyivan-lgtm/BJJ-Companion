## Логика последовательности
Phase 0 сначала: сломанный первый контакт (фриз) и перекошенные рекомендации (нет health-goal) обесценивают любые новые фичи; телеметрия нужна, чтобы мерить дальше. Phase 1 - самый дешёвый рычаг удержания (лечит причину №1 отмены «забыл открывать»). Phase 2 (видео) дороже и контентозависимо → после петли. Phase 3 (тренер) - рост, но требует новых фич + продаж → когда ядро удерживает. Phase 4 - только когда удержание доказано данными.
