# Ревизия ролевых связей графа техник (setup_from / chain_to)

Дата: 2026-07-26. Ветка: `fix/situations-graph-roles`.

## Проблема
В разделе «Что если» техники попадали не на ту роль-сторону: напр. «Мост из маунта»
(эскейп, ход НИЖНЕГО) показывался под «Маунт: держу» (верхний). Это не баг витрины, а
дефект данных: ролевые рёбра `setup_from`/`chain_to` в `data/techniques.csv` ссылались на
карту-позицию противоположной роли.

## Корень и охват
Позиции смоделированы двумя роль-карточками (id 1 «Играешь закрытый гард» / id 2
«Проходишь закрытый гард»; 16 «Держишь маунт» / 15 «Под маунтом» и т.д.). Одни и те же
рёбра кормят четыре поверхности, поэтому ошибка видна везде:
- `/map` (`flowLayout.ts`): `setup_from` = «Откуда попадаешь», `chain_to` = «Что дальше».
- Карточка техники (`technique.$id.tsx`): «Заходы из», «Продолжения», «Похожие».
- «Что если» (`situations.tsx`).
- Генератор/`caught.ts` — второстепенно (там `setup_from` фильтруется по сабмишенам).

Поэтому фикс сделан в ДАННЫХ (CSV → `build-data`), а не фильтром витрины.

## Правило ролей (детерминистическое)
- Эскейп/ретеншн ссылается на защитную сторону: верхняя доминантная -> нижняя (16->15,
  17->18 ...), «Прохожу» -> «Играю» (2->1, 4->3 ...).
- Проход (`guard_pass`): «Играю» -> «Прохожу» (1->2, 3->4, 5->6, 8->445, 381->331 ...);
  ссылки на нижнюю доминантную (13) убраны.
- Свип: «Прохожу» -> «Играю» (2->1, 4->3, 6->5 ...).
- `chain_to` карточек позиций, ведущие в чужую роль (напр. «Играю» -> проход, «Прохожу» ->
  свип/эскейп, нижняя карта -> консолидация верха «Спина->Маунт»), удалены. Рёбра хранятся
  на обеих сторонах, поэтому парные `setup_from` тоже почищены (452 ∌ 18, 459/460 ∌ 23,
  458/342 ∌ 20), чтобы слот реально очистился; корректная верхняя сторона (17/22/19)
  сохранена.

## Итог
58 строк CSV изменено. Групповых ролевых инверсий в «Что если»: 52 -> 1.
Валидатор `build-data` чист (335 техник, ссылки валидны), `vitest` 139/139.
Побочный плюс: проходы теперь корректно появляются под «Прохожу» (раньше часть
отсутствовала на нужной стороне; напр. лег-драг 94).

Проверено рантаймом (DOM, скриншоты превью для этого приложения таймаутят):
- «Маунт: держу» -> секции только Атаки/Переходы (эскейпа больше нет).
- «Маунт: под» -> «Мост из маунта» на месте; «Спина->Маунт» ушёл из Переходов.
- Карточка «Мост из маунта» -> «Заходы из: Под маунтом» (было «Держишь маунт»).

### Остаточное (осознанно не трогали)
«Седло: Защита» (слот id 328) подкреплён карточкой `guard_pass` «Проход через седло», из-за
чего в нём виден «Проход Ханихол» (334) — это выбор структуры слота (защита от седла = выйти
из растяжки), а не ролевая инверсия вроде моста из маунта. При желании выносится отдельно.
