## Здоровье ядра (детально)

**Стор (store.ts) — здоров, SSR-safe.** localStorage читается в `useEffect`, а не в инициализаторе `useState` (соблюдён грабли из CLAUDE.md); дефолты в инициализаторе. Общая шина у 5 из 6 хуков (исключение — `useDiary`, п.2). Облачная синхронизация best-effort с 3s timeout, merge `{...remote, ...local}` (локальное главнее по ключу — корректно для статус-мапы, `not_started` не хранится). Выгрузка гейтится `hasConsent()` во всех отправщиках (`trySyncToCloud/Notes/Favorites`) — сверено.

**Латентный footgun (не баг сейчас):** module-level синглтоны (`profileSnapshot`, `progressSnapshot`, `notesSnapshot`, `reviewedSnapshot`, `favoritesSnapshot`) на сервере разделяются между SSR-запросами. Сейчас безопасно: пишутся только в client-only `useEffect`/колбэках, на сервере остаются `null` (`readJSON` отдаёт fallback при `window===undefined`). Но любой будущий вызов `publish*()` во время рендера/SSR утечёт данные между пользователями. Стоит комментом-предупреждением у объявлений.

**recommend.ts — cycle-safe.** `learningPath` защищён `visited` + `MAX_PATH_LEN=6` (prerequisites не-DAG, 254/293 в циклах — грабли соблюдены). `nextToLearn` round-robin по группам, `isUnlocked` только по prerequisites. Чисто, детерминированно, покрыто тестами.

**flowLayout.ts — синхронная зональная раскладка** без ELK, детерминирована, колонка альтернатив отводится за самый широкий ряд (наложения исключены конструктивно). Хорошо изолирована.

**stats.ts / xp.ts** — чистые, выводимые (XP не хранится, считается из дневника/прогресса/пояса). `stats` берёт вторую ось из `tags` (не из `styles`) — намеренно, чтобы не дублировать архетип. Оба покрыты. Тонкость (задокументирована в CLAUDE.md): `computeTotalXp` reward может разойтись с тоталом при смене архетипа новой записью — spec-ack, не баг.

**build-data.mjs** — валидатор ссылок/дублей/самоссылок/пустых полей строгий (падает при ошибке); циклы prerequisites — предупреждение, не ошибка (осознанно). Свой CSV-парсер с кавычками — компактный, корректный.
