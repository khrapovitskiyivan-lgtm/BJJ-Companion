# Кабинет тренера (B2B-трек) — план на будущее

Статус: **ЗАПЛАНИРОВАНО, не начато.** Строить только после консьерж-валидации (см. ниже).
Согласовано с пользователем (2026-07-28) + два независимых специалиста (продуктовый + рыночный).

## Модель (крючок вокруг тренировки)
Идея пользователя: реальная боль тренера — «что давать на тренировке», плюс ученики
приходят неподготовленными. Приложение помогает тренеру решить тему и **анонсировать до
тренировки**, ученики готовятся и приходят в курсе → лучше результат + мост «понимание→тело».

Это сильнее «домашки после класса»: даёт тренеру постоянную ценность (повод открывать
каждую неделю) и праймит учеников. Юридически легче: анонс — вещание сверху вниз, тренеру
НЕ нужно видеть дневники учеников (самый тяжёлый 242-ФЗ-риск отпадает в фазе 1).

## Что строим (когда дойдём)
- **Отдельная вкладка внизу**, видна ТОЛЬКО тренеру (условный рендер), перед «Моя игра».
  Нижняя навигация станет 5 табов у тренера, 4 у ученика.
- **Роль тренера — самообслуживание:** создал клуб по инвайтам → стал тренером → вкладка
  появилась. Без ручной выдачи ролей. **Аккаунты НЕ привязывать к залу** (иначе уход из
  зала = уход из приложения; приложение прежде всего личный дневник, клуб — оверлей).

### Фаза 1 (клин) — АНОНС
1. Тренер: подсказка темы (повёрнутый генератор отработки, по уровню группы/прогрессии) →
   выбирает 1-3 карточки → собирает анонс (карточки + заметка + дата) → deep-link.
2. Тренер сам постит ссылку в существующий чат зала (прав бота в группе не надо).
3. Ученик: тап → карточки с разбором → готовится перед классом → после класса подхватывает
   существующий крючок «разбери показанное».

Make-or-break (оба специалиста): главный невидимый конкурент — **бесплатный чат зала**.
Приложение обязано дать то, чего чат не даёт: (а) помочь РЕШИТЬ тему, (б) анонс несёт
готовый разбор (карточка + дрилл + видео). Если только «разослать тему» — чат выигрывает.

### Голосование за технику (опционально)
Кнопка тренера, только когда сегодня НЕ продолжение вчерашней темы. Ученики голосуют →
тренер видит спрос → тема → анонс. Замыкает цикл и даёт ученику агентность (удержание).
Осторожность: многие тренеры ведут свою прогрессию — поэтому опционально, не обязаловка.
Тестировать можно через нативный Telegram-опрос до постройки.

### Фаза 2 (собственно B2B, позже)
Дашборд ростера (посещаемость плана недели) + пуш тренеру «X не был 3 недели» + платный
кабинет. **Только после 242-ФЗ-резолва и явного opt-in ученика.** Тренер видит ТОЛЬКО
агрегат посещаемости, НИКОГДА — содержимое дневника/заметок/техник.

## Отклонено
- «План урока» как клин — противоречит п.25.3 (тренер импровизирует на месте, не готовится
  к классу; prep-инструмент получит низкое использование). Анонс ≠ план урока: анонс это
  «вот тема, готовьтесь», а не «вот расписанный класс».

## Переиспользуем
Инфра клуба/партнёров (инвайт deep-link `?startapp=`, ростер, агрегаты профиля), генератор
отработки, карточки техник, крючок разбора (reviewQueue/ReviewShownBlock), шеринг (share.ts),
телеметрия.

## Строим новое (минимум)
Сущность «клуб» (coach_id + участники, поверх партнёрских рёбер), payload анонса
(technique_id[] + заметка + дата, шарится параметром), экран тренера «Анонс группе»,
лендинг ученика «Анонс от тренера».

## Экономика (рыночный специалист)
«Зал платит за удержание» — недоказуемая продажа без кейса; RU-потолок ~1000-2000₽/мес с
зала = 1-4 индивидуальные B2C-подписки, не кратно больше. Модель если что: **freemium
ученикам + платный кабинет тренеру 990-1990₽/мес**, ТОЛЬКО после доказанного использования.

## Пререквизит перед постройкой (обязательно)
1. **Консьерж-тест на своём/дружественном зале, 2-4 недели:** тренер руками кидает в чат
   зала анонс из готовых ссылок-карточек; при новой теме — Telegram-опрос. Мерить: открывают
   ли ученики и готовятся; продолжает ли тренер сам 2-3 недели; лучше ли идёт класс.
2. Интервью 3-5 тренеров (ведут ли конспект, стали бы анонсировать, есть ли живой чат зала).
3. Параллельно — добрать телеметрию консьюмерской петли (доказать, что личный пользователь
   возвращается). Дистрибуция недоказанного продукта убивает быстрее, чем её отсутствие.

Строить кабинет ТОЛЬКО если консьерж показал: тренер продолжает сам + ученики готовятся.

## Порядок
Консьерж + телеметрия петли → фаза 1 (анонс + опц. голосование) → фаза 2 (дашборд/платно).
