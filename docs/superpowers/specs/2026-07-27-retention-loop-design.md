# Спека: петля удержания — движок insights + «3 минуты сегодня» (2026-07-27)

## Контекст
Фичи 2+3 роадмапа. Два независимых эксперта: (1) HYBRID — общий чистый движок + тонкие рендереры; (2) валидация — триггер важнее экрана, настоящая ценность = консолидация 4 реко-блоков, cold-start слаб. Спайк снял пороги (см. ниже). Видео — пока нет (решение пользователя).

Роадмап: [2026-07-27-roadmap.md](../../analysis/2026-07-27-roadmap.md), фичи 2+3.

## Цель
Замкнуть петлю «дневник → вывод → одно действие сегодня» и дать пушу осмысленную цель. Первый инкремент: движок + экран «3 минуты сегодня» (консолидирует 4 реко-блока) + привязка существующего пуша к экрану.

## Не-цели (вне первого инкремента)
- R3 месячный дайджест (позже, тот же движок).
- Видео-слот в карточку.
- Новая инфраструктура пуша сверх минимума (см. «Триггер»).
- EN-локализация.

## Архитектура

### 1. Движок `src/lib/bjj/insights.ts` (чистый, НА КЛИЕНТЕ)
Сервер содержимого дневника не видит — движок живёт на клиенте (как tgReport/партнёры).

```
type InsightKind = "cold-start" | "catcher-defense" | "review-shown" | "repeat-stale" | "plan" | "learn-next";
interface Insight { kind: InsightKind; weight: number; techniqueIds: number[]; reason: string; route: string }
computeInsights({ entries, progress, reviewed, belt, goal, gi, noGi, frequency, techniques, today }) -> Insight[]  // сортирован по weight desc
primaryAction(insights) -> Insight | null   // = insights[0]
```

Виды и КАЛИБРОВКА (пороги подтверждены спайком):
| kind | источник (существует) | окно/порог | weight |
|---|---|---|---|
| `catcher-defense` | `topCatchers` + `defensesFor`, минус изученные защиты | **окно 30 дней** (НОВОЕ), порог 2+ | `100 + count*10` |
| `review-shown` | `pendingReview` | 7 дней, cap 6 | `80` |
| `repeat-stale` | изученное, 3+ нед нет в дневнике | 21+ дней | `70` |
| `plan` | `todayCardModel` | недобор недели, дни остались | `60` |
| `learn-next` | `nextToLearn` (goal-aware) | — | `40` |
| `cold-start` | нет записей за 7 дней / дневник пуст | — | `200` (перебивает всё) |

- **Окно ловцов (НОВОЕ):** добавить в `caught.ts` вариант с окном по дате (`topCatchers(entries, limit, {sinceMs})`) — старые паттерны не доминируют вечно. Обратная совместимость: без окна = как сейчас.
- **cold-start (НОВОЕ, закрывает провал спайка A/F):** когда за 7 дней нет записей — primary = реальное дневное действие: «Запиши тренировку за 30 секунд» (route `/diary?add`) ИЛИ, если дневник совсем пуст, «Ментальная репетиция базовой техники» (route на базовую карточку). НЕ переупакованный `nextToLearn`. Вес 200 — перебивает контент: нет смысла показывать защиту тому, кто перестал логировать; сначала вернуть к записи. ОТКРЫТАЯ КАЛИБРОВКА (спайк не покрыл): «залогировал давно, но есть сильный паттерн» — не занудствовать ли; проверить доп. сценарием/данными перед финалом.
- `repeat-stale`: если логики нет отдельной чистой функцией — извлечь из `progress.tsx` в `insights`-хелпер (без изменения поведения).
- Ротация свежести (вторично): при равенстве catcher-весов primary чередуется по дню (детерминированно от `today`), чтобы не долбить одним ловцом.

### 2. Рендерер R1 — `TodayAction` на «Моей игре»
Новый блок `src/components/bjj/TodayAction.tsx` В ВЕРХУ «Моей игры» (после `ProgressTop`):
- **Герой:** `primaryAction()` — заголовок из `reason`, строка(и) техник `TechniqueRow`, кнопка действия по `route` (карточка / `/workout?src=diary` / `/diary?add`).
- **«Что ещё сегодня» (раскрытие):** остальные `insights` списком — это и есть контент прежних 4 блоков, но ранжированный и свёрнутый.
- Пустых состояний нет: cold-start/plan/learn-next всегда дают primary.

**Консолидация 4 реко-блоков** (решение к ревью пользователя): TodayAction ЗАМЕНЯЕТ отдельные блоки «Разбери показанное» (`ReviewShownBlock`), «Что тебя ловит», «Пора повторить», «Текущий фокус/Следующая цель» — их контент теперь в ранжированном списке движка. Тап по строке = карточка техники (сохраняем ценность, которую отмечал UX-эксперт). «Разрыв»/«Твой стиль»/«Характеристики» — НЕ трогаем (это идентичность, не действия).

### 3. Триггер (пуш) — вместе с экраном
- Существующий вечерний soft-пинг (`tgRemind.decide`) уже открывает Mini App → пользователь попадает на «Мою игру», где теперь есть TodayAction. Убедиться, что web_app-кнопка ведёт на экран с TodayAction (start_url `/progress`).
- ДОБАВИТЬ утренний нудж выходного «3 минуты повторить» — новый kind в `decide()` + слот крона (`api.tg-cron.ts`). Текст счётчиковый/обезличенный (сервер не знает дневник), тап открывает экран, движок показывает конкретику.
- Честно: в локальном режиме пушей нет (ограничение, не баг).

### 4. Телеметрия
`insight_shown` (detail=kind primary) при показе, `insight_click` (detail=kind) по действию. Расширить whitelist `bjj_track` (SQL, применяет пользователь). Локальный режим не шлёт.
