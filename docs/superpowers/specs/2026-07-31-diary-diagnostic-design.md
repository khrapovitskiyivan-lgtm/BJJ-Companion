# Спека: Дневник — диагностика, выигрыши, единый копирайт

Дата: 2026-07-31
Статус: черновик на ревью пользователя
Процесс: brainstorming (Spec-First v2). «Рычаг инструктора» (первый срез) + симметричная фича
выигрышей + аудит копирайта. Подтверждено инструктором, продуктом и UX-writer-аудитом.

ОБНОВЛЕНО (по совету двух экспертов — заход РАЗБИТ на три):
- A. ПЕРЕИМЕНОВАНИЯ — СДЕЛАНЫ отдельным пассом (ветка fix/copy-voice-consistency). Секция A ниже — исторический контекст.
- B. ДИАГНОСТИКА «Что не получилось?» — ЭТА спека, к реализации СЛЕДУЮЩЕЙ свежей сессией (правка в diary.tsx — сакральный «в два тапа» файл, нужна изолированная тщательная проверка, не хвост длинного дня).
- C. ВЫИГРЫШИ — ОТЛОЖЕНЫ до данных+дизайна. Сначала проверить `caught_logged` (сейчас 5/14дн против favorite_toggle 1 — пикер не мёртв). Узкая версия по инструктору: поле `finishedWith` (НЕ `landed`/`successRate` — коллизия с Technique.successRate), порог 2+, вшить в существующий инсайт «что ловит» (НЕ 5-й блок), без доп-XP, не анкорить генератор; в записи нет данных о сопротивлении. Секция C ниже — черновик, пересмотреть при возврате.

## Контекст

Три связанные вещи, все на поверхности дневника / «Моей игры»:
1. **Нет обратной связи после попытки** (deliberate practice отсутствует) — мост «понимание->тело».
2. **Асимметрия «поймали»**: трекаем поражения (`caughtBy` -> защиты), но не победы. При этом
   избранное почти не жмут (`favorite_toggle` 1/14дн) — «чем ты поймал» даёт ОРГАНИЧЕСКИЙ сигнал
   «твоя A-game», который человек и так отмечает в потоке.
3. **Дрейф копирайта** после многих фич + баг ясности «Чем поймали?» (кто кого).

Дневник — единственная живая петля (entry_saved 32, форма намеренно «в два тапа»); любые
добавки — необязательны и не утяжеляют быстрый лог.

## Решения (зафиксированы пользователем)

- Копирайт: см. таблицу переименований ниже; гайд голоса — `docs/design/voice-guide.md`.
- Диагностика: вопрос **«Что не получилось?»**.
- Выигрыши: поле **«Чем ты поймал?»** (симметрично «Чем тебя поймали?»; муж. род принят ради
  симметрии), блок статистики **«Что у тебя получается»**.
- Делаем ОДНИМ заходом.

## Область

**В область:** переименования (таблица), диагностика (a), выигрыши-захват (b) + блок-отдача (c),
телеметрия. **Вне области:** «умное» замыкание петли (тег -> подсказка при следующем открытии
техники — следующий срез, пока тегов нет в данных); структура дрилла (rep-протокол); раннер-таймер.

## B. Диагностика «Что не получилось?»

- **Single-select чипы**: `Захват` · `База/поза` · `Угол/тайминг` · `Реакция партнёра` · `Не уверен`.
- **Гейт показа**: только при сигнале сопротивления — `caught.length > 0` ИЛИ `intensity` задана
  ИЛИ `rounds > 0`. На быстром кооп-логе не появляется.
- **Размещение**: основной поток, после пикеров «поймали», перед заметкой. НЕ в «Подробнее».
- **Необязательно, не блокирует «Сохранить», без XP.** Уровень записи.
- **Хранение**: `DiaryEntry.struggle?: StruggleTag`; пишется в `save()`, предзаполняется при редактировании.
- **Замыкание петли (минимум)**: на экране награды (`EntryReward`/EntryRewardSheet) при заданном
  `struggle` и не `unsure` — строка «В следующий раз акцент: <STRUGGLE_LABEL[tag]>».
- **Телеметрия**: `struggle_logged` (detail = тег).

## C. Выигрыши: «Чем ты поймал?» + «Что у тебя получается»

- **Пикер в форме дневника** — симметричный «Чем тебя поймали?»: поиск по сабмишенам, чипы;
  placeholder «Чем ты поймал? Добавить сабмишен…»; подпись чипов в списке записи «Поймал:».
  Всегда показан (как caughtBy), необязателен. Хранение: `DiaryEntry.landed?: number[]`.
- **Расположение**: сразу после «Чем тебя поймали?» (пара про сабмишены), перед диагностикой.
- **Блок «Что у тебя получается»** на «Моей игре**: топ твоих финишей из `landed` (симметрично
  замыслу «Что тебя ловит»). Компактный, показывается только при непустых данных.
  - Хелпер (в `caught.ts`, рядом с caughtCounts): `landedCounts(entries)` и
    `topLanded(entries, limit=3)` -> `{ id: number; count: number }[]` сортировка по count desc.
  - Компонент: строки техник (TechniqueRow) с «N раз»; заголовок «Что у тебя получается».
    Разместить в потоке «Моей игры» (напр. рядом с «Твой стиль» — идентичность/сила).
  - Тон — позитивный (не destructive, в отличие от «ловит»).
- **Телеметрия**: `landed_logged` (симметрично `caught_logged`).

## Тестирование

- **Юнит (vitest):**
  - `topLanded`/`landedCounts`: считает и сортирует по count; пустой -> [].
  - гейт диагностики (если вынести хелпер `showStruggle(draft)`): caught/intensity/rounds включают; быстрый лог — нет.
- **Рантайм через DOM** (превью `bjj-companion`, форма/список/Моя игра — скриншоты работают):
  - лейблы: «Чем тебя поймали?», «Чем ты поймал?», «Поймали тебя:»/«Поймал:», «в отработке» в онбординге, «Хочешь и тренируешь», «Изучено» (не «Готово»), «Жёсткая» в обоих местах, «Записать тренировку»;
  - быстрый лог без сопротивления — «Что не получилось?» НЕТ; при поймали/интенсивности — появляется, single-select, пишет `struggle`; награда даёт «акцент» (не для unsure);
  - «Чем ты поймал?» пишет `landed`; блок «Что у тебя получается» на «Моей игре» показывает топ при непустых `landed`, скрыт при пустых;
  - обе темы; быстрый лог (дата+техника) не утяжелён.
- **Сборка:** `npx vitest run` зелёный; данные не трогаются.

## Риски

- **Утяжелить дневник** — снято: диагностика гейтится и необязательна; пикер выигрышей
  симметричен существующему (знакомый паттерн), необязателен; быстрый лог не меняется.
- **Пустое поле выигрышей** — снято блоком-отдачей «Что у тебя получается».
- **Плотность «Моей игры»** — блок компактный, показывается только при данных, позитивный тон.
- **Фарм** — без XP на диагностику/выигрыши.
- **Малая база** — честно: качественная валидация; инструмент для существующих.

## Критерий готовности

- Все переименования применены, голос единый (сверка с `docs/design/voice-guide.md`).
- «Что не получилось?» — гейт/необязательность/награда работают; `struggle` пишется.
- «Чем ты поймал?» пишет `landed`; «Что у тебя получается» показывает топ финишей.
- Телеметрия `struggle_logged`/`landed_logged` подготовлена (SQL позже).
- Логика `caughtBy`/защит/генератора не тронута; быстрый лог не утяжелён.
- Тесты и сборка зелёные; рантайм подтверждён через DOM в обеих темах.
