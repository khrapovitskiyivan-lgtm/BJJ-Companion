# ТЗ для Claude Design — визуальный апгрейд BJJ Companion

Дата: 2026-08-02. Цель пакета — поднять воспринимаемое качество продукта (первое впечатление, айдентика, витрина) под задачу «сделать проект продаваемым». Ядро дизайн-системы менять НЕ нужно, только эстетический слой поверх.

Каждый бриф ниже — самостоятельный: копируй нужный раздел целиком в Claude Design. После генерации агент нормализует HTML/SVG под стек (React 19 / TanStack / Tailwind CSS 4) и семантические токены, встроит и проверит рантаймом.

## ОБЩИЙ КОНТЕКСТ (вставлять в каждый бриф)

Продукт: BJJ Companion — приложение-ежедневник для бразильского джиу-джитсу (не справочник). Логируешь тренировки в дневник -> видишь статистику и «свой стиль» -> получаешь персональные рекомендации, что учить дальше. Есть граф связей 340 техник, генератор «отработки», геймификация (уровень/XP). Скоро — своя профессиональная видео-библиотека всех техник.

Платформа: Telegram Mini App + web-PWA (одна кодовая база). Проектировать МОБИЛЬНО-ПЕРВЫМ под ширину 375px. Обязательны обе темы (светлая и тёмная).

Аудитория: увлечённые практики BJJ, преимущественно белые/синие пояса, в основном iPhone внутри Telegram. Тон бренда: спортивный, уверенный, «твой умный напарник по залу», без инфантильности и без корпоративной сухости.

### Дизайн-система — СОХРАНИТЬ (не переизобретать)
- Основной цвет (navy, из логотипа): `#2b2f6b` — oklch(0.337 0.103 276.5). В тёмной теме светлеет до oklch(0.72 0.11 274).
- Золото (бренд и достижения): заливка `#c79a4e` — oklch(0.713 0.108 78.7); для текста/иконок на светлом темнее — oklch(0.54 0.11 78.7). Золото = награды, достижения, «перевыполнено», тёплые акценты. НЕ основной UI-цвет.
- Фон: светлый тёплый почти-белый oklch(0.985 0.005 95); тёмный navy-графит oklch(0.16 0.02 260). Карточки: белый / oklch(0.22 0.02 260).
- Правило «один цвет = один смысл». Статусы прогресса: серый (не начато) -> navy (в процессе) -> зелёный (изучено). Пояса — отдельная палитра пастельных полосок слева (белый/синий/пурпурный/коричневый/чёрный), их не трогать.
- Шрифт: Inter (Inter Variable). Кегли: кикер 11px uppercase tracking-widest, заголовок экрана ~20px bold, секции ~14px semibold, тело ~14-15px, вторичка 11-12px.
- Скругления: чипы/табы — полные (pill), кнопки — 12-14px (rounded-xl), карточки — 16px (rounded-2xl). Тени лёгкие, без неона/градиентных мешей. Стиль плоский, чистый.

### Формат сдачи
Self-contained HTML + inline CSS (или SVG для лого/иконок). Без внешних CDN/шрифтов с сети (webview Telegram блокирует внешние домены) — Inter подключать как системный фоллбэк-стек. Reализуемо через Tailwind-утилиты. Показать И светлую, И тёмную тему.

## БРИФ 1 — Флагманский экран «Моя игра» (задаёт визуальное направление)

Задача: эстетически поднять главный экран приложения так, чтобы он читался премиально и отличительно, задавая тон всему продукту. Сохранить состав и функции блоков, поднять визуальную иерархию, воздух, микро-детали.

Что на экране сейчас (сверху вниз), функции сохранить:
1. Шапка: слева иконка темы, по центру лого + «BJJ Companion», справа настройки.
2. Профиль-строка во всю ширину: аватар с бейджем уровня (LVL N), имя, пояс, полоска XP до следующего уровня.
3. Две колонки: слева 4 стата в рамках (Прогресс % / Изучено / В процессе / Избранное), справа блок «Сегодня» (недельный план + крупная кнопка «Записать тренировку»).
4. Блок «Сегодня · 3 минуты» — одно приоритетное действие (герой) + карточка техники.
5. «Твой стиль» (архетип игры) -> «Разрыв» (аспирация vs реальность).
6. Свёрнутые «Характеристики» (6 статов).

Хочу от тебя: свежий визуальный язык этого экрана в рамках системы — работа с иерархией (что главное на экране), ритмом отступов, hero-моментом уровня/прогресса (это геймификация, должно ощущаться наградно, тут уместно золото), аккуратными разделителями секций, состоянием «сегодня» как явным фокусом. Дай светлую и тёмную версии.

НЕ делать: не менять navy/gold/Inter/токены; не превращать в дашборд с графиками; не добавлять нижнюю навигацию сверх 4 пунктов; мобильная ширина 375px, без горизонтального скролла.

## БРИФ 2 — Логотип (компактный знак) и иконки навигации

Задача А — компактный знак логотипа. Есть полноцветный логотип (navy + золото). Нужен компактный монознак/леттермарк, который читается в шапке 24-36px, как favicon и в иконке приложения на сторах. Должен работать в одном цвете (currentColor) и на светлом, и на тёмном фоне. Идея бренда: BJJ + «путь/прогресс».

Задача Б — набор из 4 иконок нижней навигации, единый стиль (线, stroke ~1.8-2px, скругления в духе Lucide, размер ~20-24px):
- «Моя игра» (профиль/прогресс игрока) — сейчас стоит «шака», грубовата, нужен более выразительный и понятный знак.
- «Дневник» (лог тренировок).
- «Отработка» (личная тренировка-дрилл).
- «Техники» (библиотека/граф техник).
Плюс подходящая иконка 5-й под-вкладки «Старт» (дорожная карта новичка).

Хочу: SVG, currentColor, viewBox нормализованный, консистентная сетка и толщина штриха. Дай варианты знака лого (2-3) и полный сет иконок в одном стиле.

НЕ делать: не растровые (только вектор); не отходить от навигационной семантики (иконка должна угадываться); стиль в одном визуальном языке с Lucide (остальные иконки в приложении оттуда).

## БРИФ 3 — Витрина: лендинг и скриншоты для сторов

Задача: маркетинговая посадочная страница + рамки скриншотов для App Store / Google Play, под раскрутку и разговор с потенциальным покупателем. Позиционирование: «RU-first умный дневник BJJ — дневник ведёт вперёд: видишь свой стиль, прогресс и что учить дальше; скоро своя видео-библиотека всех техник».

Секции лендинга: герой (сильный заголовок + подзаголовок + CTA «Открыть в Telegram»), 3-4 ключевые ценности (дневник->инсайты, граф техник, персональные рекомендации, скоро видео), демонстрация экранов в рамке телефона, соц-доказательство (место под отзывы), финальный CTA. Тон — спортивный, уверенный.

Плюс 5-6 сторовых скриншот-кадров (1290x2796 iPhone): каждый = экран приложения в рамке + короткий заголовок-выгода сверху, в фирменных navy/gold.

Хочу: адаптивный лендинг (десктоп + мобильный), обе темы для скриншотов, фирменные цвета и Inter. Русский текст.

НЕ делать: не выдумывать метрики/отзывы (плейсхолдеры пометить как плейсхолдеры); не обещать несуществующего; не уводить от бренд-палитры.

## БРИФ 4 — Карточка техники с видео (ключевой экран будущего актива)

Задача: карточка отдельной техники — экран, вокруг которого строится главный актив (проф-видео). Спроектировать премиальную подачу с видео-плеером в фокусе.

Состав (сохранить, переупаковать визуально): шапка (назад / название техники RU + EN / избранное-корона / поделиться); строка-причина «зачем тебе это» и «дальше: X»; ВИДЕО-БЛОК (плеер) — сейчас часто пусто («видео скоро — снимаем»), нужно и красивое состояние с видео, и достойное состояние «скоро»; разделы Механика / Ключевые моменты / Когда применять / Ошибки; бейджи (пояс, Gi/No-Gi, легальность IBJJF, сложность); связанные техники (заходы из / что изучить сначала / что дальше); заметки; статус изучения.

Хочу: визуальную иерархию, где видео — герой экрана; аккуратную подачу текстовых разделов (много текста — нужен ритм и читаемость); состояние «видео скоро» как честное и премиальное, а не «пусто». Светлая и тёмная темы, 375px.

НЕ делать: не ломать систему; плеер 16:9 адаптивный; не прятать текстовый разбор ради видео (мост «посмотрел -> прочитал детали -> задрилил»).
