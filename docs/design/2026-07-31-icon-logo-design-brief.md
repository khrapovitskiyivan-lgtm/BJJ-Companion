# Дизайн-бриф: иконки и компактный знак логотипа — BJJ Companion

## О продукте
Ежедневник по бразильскому джиу-джитсу (BJJ). Формат: Telegram Mini App + web-PWA, язык RU.
Аудитория — увлечённые белые/синие пояса. Стиль интерфейса — минималистичный, линейные
иконки в идиоме библиотеки lucide-react (24×24, обводка, без заливки).

Палитра бренда: navy `#2b2f6b` (основной цвет интерфейса), золото `#c79a4e` (бренд и
достижения). Интерфейс работает в светлой и тёмной темах, поэтому иконки — ОДНОЦВЕТНЫЕ и
наследуют цвет темы (через `currentColor`).

## Нужно 3 актива

### 1. Значок нижней навигации «Моя игра» (перерисовать «шаку»)
- Сейчас: кастомная линейная иконка-шака (жест 🤙 — большой палец и мизинец врозь). Плохо
  читается на 20px: пальцы сливаются, форма «грубовата».
- Задача: перерисовать так, чтобы жест шака ЧЁТКО читался на 20px — крупнее формы, меньше
  мелких деталей. Смысл раздела: «моя игра / мой профиль бойца» (личное, не справочник).
- Можно предложить альтернативный символ, если шака в принципе не читается на малом размере,
  но сохранить «личный/игровой» смысл.

### 2. Иконка архетипа «Контроль сверху» (убрать дубль с короной)
- Проблема: игровой архетип «доминантный контроль сверху» сейчас рисуется КОРОНОЙ, но корона
  теперь занята разделом «Избранное» (коронный приём). Один глиф — два смысла, это ошибка.
- Задача: новый линейный глиф для «контроль сверху / доминирование» (образы: маунт, прижатие
  соперника, вес сверху, давление вниз). НЕ корона.
- УЖЕ ЗАНЯТЫЕ глифы набора (повторять НЕЛЬЗЯ): наковальня, ветер/поток, замок, рамка,
  круговая стрелка, следы стоп, прицел (мишень), кисть-хват, щит, корона.

### 3. Компактный знак логотипа
- Сейчас есть только полный лого-словомарк (широкий, с текстом). Нужен КОМПАКТНЫЙ знак БЕЗ
  текста — для шапки приложения, фавикона, аватара.
- Смысл: BJJ + путь/прогресс к мастерству. Палитра navy + золото.
- Дать 2 варианта: (а) двухцветный (navy+золото, с заливкой) — для фавикона/аватара;
  (б) одноцветный контурный (currentColor) — для шапки в обеих темах.

## Технические требования (обязательны — иначе не интегрируется в код)
- Формат каждого актива: **инлайн SVG**. Иконки — `viewBox="0 0 24 24"`; знак логотипа —
  квадратный viewBox.
- Иконки навигации и архетипа: `fill="none"`, `stroke="currentColor"`, `stroke-width≈2`,
  `stroke-linecap="round"`, `stroke-linejoin="round"` — как в lucide. ОДИН цвет, наследуемый
  темой. БЕЗ градиентов, БЕЗ растровых вставок, БЕЗ зашитых цветов.
- Обязательная читаемость на 16–20px (проверить в уменьшении).
- Знак логотипа: вариант (а) может быть 2-цветным с заливкой; вариант (б) — обязательно
  одноцветный контурный на `currentColor`.
- Без текста внутри иконок, без внешних шрифтов.

## Критерий приёмки
- Каждый актив — отдельный чистый SVG (вставлю в кодовую базу как компонент).
- Иконки визуально в ОДНОЙ семье с существующими lucide-глифами (толщина обводки, скругления).
- «Контроль сверху» и «шака» читаются на 20px и не конфликтуют с занятыми глифами.

## Формат передачи
Пришли HTML/SVG каждого актива (можно всё в одном HTML-файле, подписав, где что). Разработчик
(я) нормализует под `currentColor`/`viewBox` при необходимости и вставит в код.
