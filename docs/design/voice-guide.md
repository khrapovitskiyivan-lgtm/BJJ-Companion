# Гайд голоса — BJJ Companion

Кодифицирует уже действующий стиль копирайта (аудит 2026-07-31). Термины BJJ — канон в
`src/lib/bjj/glossary.ts`. Продуктовые термины-данность (не переигрывать): «отработка» =
генератор / «тренировка» = клуб; «Избранное» (не «коронка»); ролевые глаголы позиций
(играешь/проходишь/держишь/под); «Пурпурный»; «халф-гард»/«Дип халф-гард».

## Правила

1. **Везде «ты»** (2-е лицо): тело, хинты, пустые состояния, инсайты.
2. **Заголовки личного пространства — «мой/моя/мои»**, НЕ глагол в 1-м лице: «Моя игра»,
   «Мой профиль игрока», «Мои заметки». Не «Хочу и тренирую» — а «Хочешь и тренируешь».
3. **«Мы»-форма — только в приветствии онбординга** («Пройдём короткую настройку»). Дальше — «ты».
4. **1-е лицо — только в тап-фразах, которые пользователь достраивает** (обратный поиск:
   «Я был на четвереньках»). Статичный заголовок под это не попадает.
5. **Заголовки/кнопки/бейджи — sentence case, без точки.** Поясняющие подписи — с точкой.
   Настоящие вопросы к пользователю — с «?».
6. **Кнопки — глагол-инфинитив**: Сохранить, Записать, Отметить, Собрать, Запустить, Пригласить.
   Исключения только: «Отмена», «Далее»/«Назад». Голое существительное на кнопке — нельзя.
7. **Плейсхолдеры инпутов оканчиваются на «…»** при приглашении к вводу: «Найти технику…»,
   «Добавить сабмишен…».
8. **Простой русский > англицизмы** в прозе/лейблах. Исключение — названия техник/позиций и
   федераций (IBJJF, ADCC, Gi/No-Gi). Прочий жаргон — через глоссарий.
9. **«Отработка» = только генератор, «тренировка» = только клуб.** Не смешивать (несущая пара).
10. **Одно понятие — одно слово везде.** Перед новым лейблом для enum/статуса искать
    существующую подпись, а не сочинять синоним.
11. **Ясность направления.** Кто на кого действует — явно, если возможна двусмысленность:
    «Чем тебя поймали?» / «Чем ты поймал?», не «Чем поймали?».
12. **Гендер:** приложение пол не хранит. Избегать гендерных глаголов прошедшего времени по
    возможности (нейтральные существительные / настоящее время). Осознанное исключение — там,
    где симметрия важнее (поле «Чем ты поймал?» — муж. род принят ради пары с «Чем тебя поймали?»).
